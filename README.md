# Refactory-Site-Clone

A static website clone of the home page of Refactory Academy — built as a simple front-end project.

## 📄 Overview

This repo contains HTML, CSS (and possibly assets) for a clone of the Refactory Academy website. The site describes Refactory’s mission, courses (Foundational, Apprenticeship, Advanced), contact info, and other resources — such as Stories, Careers, FAQs, Privacy Policy, etc. The goal is for the clone to mimic the original site’s layout and styling for learning and practice purposes.

## 🧰 What’s Inside

- `index.html` — Main page of the site (landing page of the clone).  
- Other HTML/CSS/asset files (images, stylesheets, maybe JS) that replicate the original site’s visuals and content.  
- Probably directories like `assets/`, maybe containing images, icons, CSS, etc.  
- Contact & footer section including contact phone numbers, email addresses, and location.  

## ✅ Purpose / Use Case

- **Learning practice:** Helps you practice HTML/CSS (and optionally JS) by building or examining a real-world-looking website.  
- **Reference or demo:** You can use it to show a static site prototype or sample of a simple front-end build.  
- **Baseline for customization:** You could adapt this clone to build your own site, or further develop it (e.g. add responsiveness, interactivity, real data).  

## 🚀 How to Use / Run Locally

1. Clone the repository:  
   ```bash
   git clone https://github.com/bonanekabene/Refactory-Site-Clone.git
````

(or use the repo URL given on GitHub) ([GitHub Docs][1])

2. Navigate into the project folder:

   ```bash
   cd Refactory-Site-Clone
   ```

3. Open `index.html` in your browser (e.g. double-click or use `live server` in VS Code) to view the site.

4. Optionally: start modifying code (HTML/CSS/assets) to learn or customize.

## 🧑‍💻 How It Helps You (Given Your Current Interests)

Since you’re learning Node.js, git/GitHub, and possibly front-end frameworks:

* This static clone is a good opportunity to **observe and understand real-world static site structure**, especially HTML + CSS + assets.
* You can **practice using git and GitHub workflow** — clone, commit changes, push, branch, etc.
* Later, you could **turn this into a dynamic or component-driven site** (with Vue.js + a Node.js backend) — a great exercise bridging your learning path.
